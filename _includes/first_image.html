{%- comment -%} Outputs the src of the first in a post's rendered content, or "" if the post has none. Used for the thumbnails on the blog list, category pages, the related-post cards and the search index, which previously held four copies of this same string-splitting. Reads `fi_content` from the caller's scope rather than taking an include parameter: parameters resolve to nothing inside the related-posts loop in _layouts/post.html, so the parameter form would silently drop those thumbnails.
